# SHOOOM

Эффекты для фото и видео прямо в браузере. Всё считается на видеокарте (WebGL2), файлы никуда не загружаются, экспорт идёт в исходном разрешении.

## Запуск

Готовая сборка: `dist/index.html`. Открой её в Chrome или Edge, сервер и интернет не нужны.

## Разработка

```bash
npm install
npm run build   # src/ → dist/index.html (один самодостаточный файл)
npm test        # смоук-тест всех эффектов (один раз: npx playwright install chromium)
```

## Структура

| Файл | Что внутри |
|---|---|
| `src/index.html` | Разметка и стили; `<!--APP-->` заменяется собранным JS |
| `src/main.js` | UI, загрузка файлов, превью, экспорт фото/видео |
| `src/renderer.js` | WebGL2-движок: ping-pong проходы, мипмапы, атлас глифов для ASCII |
| `src/effects.js` | Библиотека эффектов (GLSL), группы и пресеты |
| `build.mjs` | Сборка esbuild → инлайн в один HTML |
| `tests/smoke.mjs` | Прогон всех эффектов в headless Chromium |

## Как добавить эффект

Добавь объект в `EFFECTS` в `src/effects.js`:

```js
{
  id: 'myfx', name: 'Мой эффект', group: 'Цифра',
  params: [R('amount', 'Сила', 0, 1, .5)],          // R = слайдер, S = выбор, C = цвет
  frag: `uniform float u_amount;
void main(){ vec3 c = tex(v_uv); o = vec4(c * u_amount, 1.); }`,
}
```

Ещё есть `T` (переключатель 0/1), `X` (текст, в шейдер не передаётся), `H` (заголовок раздела) и `when(p => условие, ...параметры)` — показывать параметры только при условии.
Для последовательных алгоритмов (error-diffusion дизеринг, pixel sort) эффект может задать `cpu: (src, dst, w, h, p, {px, time}) => {}` вместо или вместе с `frag` (`cpuWhen` выбирает путь) — см. `src/cpu.js`.

Каждый параметр попадает в шейдер как `u_<id>`. Общие униформы: `u_tex`, `u_res`, `u_time`, `u_px`.
`u_px = min(w,h)/1080`: умножай на него размеры в пикселях, тогда превью и 4K-экспорт выглядят одинаково.
`v_uv.y = 0` — верх картинки. Флаг `mips: true` включает мипмапы входа (для `textureLod`).

## Экспорт видео

Через [Mediabunny](https://mediabunny.dev) и WebCodecs: декодирование → шейдеры → кодирование в MP4. Кодек выбирается автоматически (H.264 → H.265 → VP9 → AV1), звук копируется без перекодирования, поворот с телефона учитывается.
